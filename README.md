This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

Let's say you wanted to go from point A to point B in either the quickest or cheapest way possible. It seems that there's an airport just 100 miles away that will save you 200 dollars but there's another flight 200 miles away that will save you even more. Maybe you don't want to travel all those 200 miles, or maybe you don't have a vehicle or a clue of how to get there. Have no fear for, as the FAA (Federal Aviation Administration) said, extraordinary circumstances are here! You are able to find flights, trains, buses, or even the quickest route on how to get to your destination all on one screen. We decided to proceed with this project as we lost our hackathon member/friend to the great groundstop of '26 so he was not able to get here as we scrambled to find ways in which he could get here the fastest way possible. Unfortunately, there we no places that had what we needed or wanted, but luckily, the circumstances fit this extraordinary site.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
